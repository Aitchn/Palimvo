Plugins can now change the interface in three ways: a colour and font theme (chosen in Settings, filtered to custom properties only), entries in the top bar, the file right-click menu, the command palette, a status bar and the settings dialog, and whole-page apps that take over the main area. Three example plugins live in `plugins/examples`.
