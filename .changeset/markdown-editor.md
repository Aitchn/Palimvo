Add the Markdown editor: live preview with wikilinks (click and `[[` completion), `![[embeds]]`, callouts, tables, task lists, KaTeX, Mermaid, highlighted code blocks and a collapsible properties block; a reading view; automatic saving that never overwrites a newer version (with a conflict choice) and keeps unsent text across a closed tab or lost connection.
