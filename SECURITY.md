# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private vulnerability
reporting: <https://github.com/Aitchn/Palimvo/security/advisories/new>.

Include what you found, how to reproduce it, and the version or commit. You will get an
acknowledgement, and we will coordinate a fix and disclosure with you.

## Supported versions

Palimvo is pre-alpha; only the latest `main` is supported.
